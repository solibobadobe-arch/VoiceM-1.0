# VoiceM 1.1.0

**Голосовой ввод в любое поле ввода Windows.** Кликни в поле, зажми клавишу, говори — чистый текст вставится сам. Распознавание полностью локальное (faster-whisper), интернет не нужен.

## Скачать

Готовые файлы — во вкладке [Releases](../../releases):

- `VoiceM-Setup-1.1.0.exe` — установщик со вшитой моделью (работает сразу после установки)
- `VoiceM-portable-1.1.0.zip` — портативная версия

## Как пользоваться

1. Кликни в любое поле ввода (чат, браузер, Word…).
2. Зажми **правый Alt** — внизу экрана появится зелёная полоска с волнами.
3. Говори свободно — слова-паразиты («э», «ну», «типа», «короче») уберутся сами.
4. Отпусти клавишу — текст вставится в поле. `Esc` — отмена.

## Окно настроек (1.1.0)

После установки VoiceM открывает своё окно. Слева сверху — **три полоски**: по клику с плавной анимацией выезжает боковое меню.

Разделы меню:

- **Главная** — текущая клавиша, индикаторы модели / микрофона / перехвата клавиш, краткая инструкция
- **Распознавание** — язык, модель, удаление слов-паразитов, автопунктуация, способ вставки, показ полоски волн
- **Горячая клавиша** — кнопка «Назначить клавишу» (перехват любого сочетания) и режим удержание / переключение
- **Доступы Windows** — проверка доступа к микрофону, выбор устройства записи, кнопки в параметры Windows (микрофон, звук, конфиденциальность, автозагрузка, уведомления), проверка перехвата клавиш и перезапуск от администратора
- **Система** — ползунок **«Запускать вместе с Windows»**, запуск свёрнутым, крестик сворачивает в трей, быстрые ссылки на config.json и журнал
- **История** — последние распознанные фразы, двойной клик — копирование
- **О программе** — версия и состояние модели

Окно можно скрыть кнопкой «Свернуть в трей» — программа продолжает работать. В трее: «Открыть VoiceM», «Настройки», «Доступы Windows», «Выход».

## Настройки (`%APPDATA%\VoiceM\config.json`)

| Ключ | По умолчанию | Описание |
| --- | --- | --- |
| `hotkey` | `right alt` | Горячая клавиша |
| `mode` | `hold` | `hold` — удержание, `toggle` — переключение |
| `language` | `ru` | Язык речи (`ru`, `en`, `auto`) |
| `model` | `small` | `tiny`, `base`, `small`, `medium` |
| `remove_fillers` | `true` | Убирать слова-паразиты |
| `auto_punctuation` | `true` | Заглавные буквы и точки |
| `insert_mode` | `paste` | `paste` или `type` |
| `input_device` | `null` | Микрофон (`null` — по умолчанию) |
| `show_overlay` | `true` | Полоска с волнами внизу экрана |
| `close_to_tray` | `true` | Крестик сворачивает в трей |
| `start_minimized` | `false` | Запускаться свёрнутым |
| `keep_history` | `true` | Сохранять историю в памяти |
| `autostart` | `false` | Автозапуск с Windows |

## Структура проекта

```
src/voicem/
  main.py           точка входа, трей, связка всего
  window.py         окно с бургер-меню и страницами настроек
  widgets.py        ползунки-переключатели, карточки, индикаторы
  system_access.py  автозапуск и доступы Windows
  overlay.py        зелёная полоска с волнами
  audio.py          запись с микрофона
  transcribe.py     локальное распознавание (faster-whisper)
  filler.py         чистка слов-паразитов
  hotkey.py         горячая клавиша
  inserter.py       вставка текста
  theme.py          чёрно-зелёная тема
  config.py         настройки
installer/voicem.iss  установщик Inno Setup
.github/workflows/build.yml  сборка exe + установщика
```

## Сборка вручную (Windows)

```powershell
pip install -r requirements.txt
pip install pyinstaller pillow huggingface_hub
python tools/make_icon.py
python tools/fetch_model.py small
pyinstaller VoiceM.spec --noconfirm
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\voicem.iss
```
