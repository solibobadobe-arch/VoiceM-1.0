# VoiceM 🎤

**Голосовой ввод в любое поле ввода Windows.** Зажал клавишу → сказал → чистый текст сам появился там, где курсор.

Работает **полностью офлайн** на бесплатной локальной модели (faster-whisper). Никаких ключей, подписок и отправки голоса в интернет.

## Возможности

- **Горячая клавиша** — по умолчанию правый **Alt**: держишь — пишет, отпустил — вставляет
- **Полоска с волной** внизу экрана — видно, что запись идёт, волны реагируют на голос
- **Удаление слов-паразитов** — «э», «ну», «типа», «короче», «в общем», «uh», «um» и др.
- **Чистка заиканий** — «я я я думаю» → «Я думаю»
- **Автопунктуация** — заглавные буквы и точка в конце
- **Работает везде** — Telegram, Chrome, Word, VS Code, любое поле ввода
- **Чёрно-зелёная тема**, иконка в трее, автозапуск с Windows

Пример работы чистки:

| Сказали | Вставилось |
|---|---|
| э ну типа короче я хочу чтобы ты ты ты сделал отчёт по продажам вот | Я хочу чтобы ты сделал отчёт по продажам. |

## Установка

Скачай **`VoiceM-Setup-1.0.0.exe`** в разделе [Releases](../../releases) и запусти. Модель распознавания уже вшита в установщик — докачивать ничего не нужно, программа работает сразу после установки.

При первом запуске Windows может показать «SmartScreen» — нажми *Подробнее → Выполнить в любом случае* (установщик без платной цифровой подписи).

## Как пользоваться

1. Кликни в любое поле ввода
2. Зажми и держи **правый Alt** — внизу появится зелёная полоска с волной
3. Говори
4. Отпусти клавишу — текст вставится сам

**Esc** во время записи — отмена.

## Настройки

Файл: `%APPDATA%\VoiceM\config.json` (трей → «Открыть файл настроек»).

| Параметр | Значения | По умолчанию |
|---|---|---|
| `hotkey` | `right alt`, `ctrl+space`, `f9`… | `right alt` |
| `mode` | `hold` — держать, `toggle` — нажать/нажать | `hold` |
| `language` | `ru`, `en`, `auto` | `ru` |
| `model` | `tiny`, `base`, `small`, `medium` | `small` |
| `remove_fillers` | `true` / `false` | `true` |
| `auto_punctuation` | `true` / `false` | `true` |
| `insert_mode` | `paste` (быстро), `type` (побуквенно) | `paste` |

После изменений перезапусти VoiceM.

## Сборка из исходников (Windows)

```bash
pip install -r requirements.txt
pip install pyinstaller pillow huggingface_hub
python tools/make_icon.py
python tools/fetch_model.py small
pyinstaller VoiceM.spec --noconfirm
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\voicem.iss
```

Готовый установщик — в `dist_installer/`.

Запуск без сборки: `python run.py`.

## Автоматическая сборка

GitHub Actions (`.github/workflows/build.yml`) собирает установщик на `windows-latest` при каждом пуше в `main` и публикует его в Releases. Размер модели можно выбрать вручную: **Actions → Build VoiceM installer → Run workflow**.

## Если что-то не работает

- **Клавиша не срабатывает в некоторых программах** — запусти VoiceM от имени администратора
- **Нет звука / пустой текст** — проверь микрофон по умолчанию в Параметрах Звука Windows
- **Тормозит на слабом ПК** — поставь `"model": "base"` или `"tiny"`
- **Логи**: `%APPDATA%\VoiceM\voicem.log`
